# Roadmap

Arvexo Radar развивается по критериям выхода, без неподтверждённых календарных обещаний:

1. Dataset audit и ML spikes.
2. Secure ingest foundation.
3. Local analytics core.
4. Generative layer через provider abstraction.
5. Executive dashboard и PDF.
6. Hardening и воспроизводимая сдача.

После MVP отдельно рассматриваются production IAM, connectors, outcome/ROI data, object storage/observability, feedback workflow и incremental processing. Они не входят автоматически в v0.1.0.

Полный scope, exit criteria, dependencies и blockers: [docs/18-roadmap.md](./docs/18-roadmap.md).
